# Laizhen Li's Academic Homepage

Source code for [lilaizhen.github.io](https://lilaizhen.github.io), built with [AcadHomepage](https://github.com/RayeRen/acad-homepage.github.io).

## Editing the site

- Site-wide identity and contact links: `_config.yml`
- Homepage content: `_pages/about.md`
- Navigation links: `_data/navigation.yml`
- CV PDF: `files/Laizhen-Li-CV.pdf`

After editing, commit and push to `main`. GitHub Pages will rebuild the site.

## Local preview

Install Ruby, Bundler, and Jekyll, then run:

```bash
bash run_server.sh
```

Open `http://127.0.0.1:4000` in a browser.
